About AgriPrice Rwanda

AgriPrice Rwanda was developed for the Final Assessment Test (FAT) — Advanced Web and Internet Programming. It addresses market information asymmetry across border markets in Rubavu and Gisenyi.

The system enforces database integrity constraints, outlier detection algorithms, atomic transactions, XML daily bulletin exports with XSLT/XPath, client-side MVC watchlists, and secure agent authentication.

Key Monitored Hubs

  • Gisenyi Central Market: Principal retail hub near Grand Barriere border.
  • Rubavu Cross-Border Market: High-volume Petite Barriere regional produce hub.
  • Mahoko Modern Market: Agricultural collector hub along Rubavu highway.
  • Nyabugogo Central Market: Kigali terminal connecting harvest supply chains.
